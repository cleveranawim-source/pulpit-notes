# 자동 스크롤 설계 (강단노트 1.0.2)

2026-10-04 · 사용자와 정한 내용

## 목적

강단 화면에서 원고가 일정한 빠르기로 천천히 올라가게 한다. 두 가지로 쓴다.

- **설교하는 내내:** 말하는 속도에 맞춰 흐르다가, 예화나 즉흥으로 말할 때 잠깐 멈췄다가 다시 흐른다.
- **리허설:** 설교 전에 일정한 속도로 원고를 끝까지 훑어본다.

## 범위

- **강단 화면에서만.** 준비 화면은 펜슬 필기용이라 넣지 않는다. 리허설도 강단 화면에서 한다.
- 타이머와는 **따로 움직인다.** 자동 스크롤을 멈춰도 타이머는 흐르고, 반대도 그렇다.

## 화면과 조작

### 자동 스크롤 버튼과 조절판

> 2026-10-04 바꿈: 처음엔 오른쪽 아래 동그란 버튼이었다. 사용자가 "기능이 있는지 모르겠다"고 해서 위쪽 막대로 옮겼다.

- 강단 화면 **위쪽 막대, 타이머 설정(25분) 바로 오른쪽**에 "자동" 버튼(그림 + 글자)을 둔다.
  - 폭 760 이하(아이패드 미니 세로)에서는 그림만 보인다.
  - 강단 화면에서만 보인다.
- **버튼을 누를 때**
  - 꺼져 있으면: 켜고, 흐르기 시작하고, 조절판을 연다.
  - 켜져 있으면: 조절판만 연다.
- **조절판:** `[❚❚ / ▶] [−] 속도 9 [+] [⏱ 시간에 맞추기] [✕ 끄기]`
  - 위쪽 막대 **바로 아래 오른쪽**에 뜬다(오른쪽 12px + 안전 영역).
  - 불투명 배경이다(밝게·종이 = `--bar-solid`, 어둡게 = 어두운 색).
- **조절판 접기:** 조절판을 마지막으로 건드린 뒤 5초가 지나면 닫힌다. 원고는 그대로 흐른다.
- **버튼의 상태 표시:** 켜져 있으면 버튼이 강조색이 되고 작은 점이 켜진다(흐르는 중 = 초록, 멈춤 = 회색).
- **[✕ 끄기]:** 자동 스크롤을 끄고 조절판을 닫는다. 탭은 원래 넘기기로 돌아간다.

### 자동 스크롤이 켜져 있는 동안(흐름·멈춤 모두)의 탭

| 자리(원고 영역 폭 기준) | 동작 |
|---|---|
| 왼쪽 25% | 조금 뒤로: 화면 높이의 1/5, 부드럽게 |
| 가운데 50% | 멈춤 ↔ 다시 흐름 |
| 오른쪽 25% | 조금 앞으로: 화면 높이의 1/5, 부드럽게 |

- 자동 스크롤이 꺼져 있으면 탭은 지금처럼 동작한다(왼쪽 30% = 이전 화면, 나머지 = 다음 화면).
- **조절판·버튼 위의 탭은 원고 탭으로 세지 않는다.**
- **손바닥 거르기는 그대로 적용한다.** 손바닥이나 펜슬을 뗀 직후의 터치는 멈춤·이동을 일으키지 않는다.
- **손가락으로 끌어 스크롤하는 동안**은 자동 이동을 쉬고, 손을 떼면 그 자리부터 다시 흐른다.

### 페달·키보드

- 지금처럼 한 화면씩 넘긴다(`turn`).
- 넘긴 자리부터 계속 흐른다.

### 스스로 멈추거나 꺼지는 경우

| 상황 | 동작 |
|---|---|
| 원고 끝에 닿음 | 멈춤 + "원고의 끝이에요" 알림 |
| 준비 화면으로 바꿈 | 끔 |
| 서재로 나감(`closeDoc`) | 끔 |
| 앱이 뒤로 감(화면이 안 보임) | 이동을 쉼. 다시 보이면 이어서 흐름(켜진 상태는 유지) |

## 속도

- **속도 단계 1~20**(소수 허용). 한 단계에 약 17%씩 빨라진다.
  - 이동 빠르기(CSS px/초) = `0.0045 × 쪽 표시 폭 × 1.17^(속도 − 9)`
  - 쪽 표시 폭에 비례하므로, 가로로 돌리거나 확대해도 글자 기준 빠르기가 같다.
  - 속도 9는 A4 설교 원고 한 쪽을 약 4~5분에 읽는 빠르기다. 속도 1은 약 3.5배 느리고, 속도 20은 약 5.6배 빠르다.
- **표시:** 정수면 "속도 9", 소수면 "속도 7.4"처럼 소수 첫째 자리까지.
- **−/+:** 가까운 다음 정수 단계로 옮긴다. 범위는 1~20이다.
  - 7.4에서 +를 누르면 8, −를 누르면 7이다.
- **기억:** `settings.autoSpeed`에 저장한다. 기본값은 9다.

### ⏱ 시간에 맞추기

- **남은 분량** = `scroller.scrollHeight − scroller.clientHeight − scroller.scrollTop`(px)
- **남은 시간**(초):

  | 타이머 상태 | 남은 시간 |
  |---|---|
  | 시작 전 | 정한 시간 전체 |
  | 흐르거나 멈춤 | 정한 시간 − 흐른 시간 |
  | 스톱워치 | "알려 줄 시간" − 흐른 시간 |

- **필요한 빠르기** = 남은 분량 ÷ 남은 시간 → 위 식을 거꾸로 풀어 속도를 구한다. 속도는 1~20 안으로 맞춘다.
- **알림**

  | 경우 | 처리와 알림 |
  |---|---|
  | 남은 시간 ≤ 0 | 속도를 바꾸지 않고 "남은 설교 시간이 없어요" |
  | 남은 분량 ≤ 0 | "원고의 끝이에요" |
  | 속도 1·20에서 잘림 | "가장 느린(빠른) 속도로 맞췄어요" |
  | 맞춤 성공 | "25분 안에 끝나도록 맞췄어요 · 속도 7.4" |

- 멈춰 있었다면 맞춘 뒤 흐르기 시작한다.

## 움직임(발열)

- 한 번에 **화면 점 하나**만큼 민다. 아이패드에서는 0.5 CSS px(기기 화소 1개)다.
- 다음 이동까지 기다리는 시간 = 한 번에 미는 거리 ÷ 빠르기. 단, **33ms(1초에 30번)보다 짧아지지 않게** 한다. 빠를 때는 한 번에 더 많이 민다.
  - 예: 쪽 폭 1008px, 속도 9 → 4.5px/초 → 0.5px씩 1초에 약 9번.
- **위치 계산:** 위치는 실수로 누적한다. 시작 시각과 그동안 흐른 시간으로 계산해서 타이머가 늦게 깨어나도 밀리지 않게 한다. 멈춤 ↔ 흐름 때는 기준점을 다시 잡는다.
- **소수 위치를 못 쓸 때:** `scrollTop`에 소수가 안 먹는 환경이면 1 CSS px 단위로 바꾼다. 시작할 때 한 번 확인한다.
- **멈춤이면 타이머를 걸지 않는다**(깨움 0).
- 다음 쪽은 기존 `updateVisible`(스크롤 때 화면 1.6장 앞까지 미리 그림)이 그린다. 따로 손대지 않는다.

## 화면 꺼짐 방지와의 맞물림

- 자동 스크롤이 **흐르는 동안**에는 15분·90분 자동 해제를 하지 않는다(`tick` 안의 조건에 추가).

## 코드 구성

- **`app.js`:** 강단 모드 코드 옆에 `// ── 자동 스크롤 ──` 구역을 둔다.
  - 상태: `A = { on, running, speed, pos, t0, timer }`
  - 함수: `autoOn()` · `autoOff()` · `autoToggle()` · `autoNudge(dir)` · `autoFit()` · `autoStep()` · `renderAuto()`
- **탭 처리:** `pointerup`의 강단 탭 분기에서 `A.on`이면 새 영역 규칙을 따른다.
- **연결:** `setMode`/`closeDoc`은 `autoOff()`를 부른다. `visibilitychange`는 이동을 쉬었다가 이어 간다.
- **`index.html`:** 버튼·조절판 마크업과 CSS. 강단 전용(`pulpit-only`), 폭 800 이하 배치도 넣는다.
- **설명서 7장:** 자동 스크롤 문단 하나(탭 영역 · 속도 · 시간에 맞추기).
- **문서:** `store/listing.md` 1.0.2 새 기능 한 줄, `README.md`에 설계 요약.

## 확인

- **헤드리스 시험(`tauto.mjs`)**
  - 속도 9·1·20의 실제 이동 빠르기(10초 평균, 식과 ±5%)
  - 가운데 탭으로 멈춤 → 이동 0, 다시 탭으로 흐름
  - 왼쪽·오른쪽 탭은 화면 높이의 1/5만큼 이동
  - 원고 끝에서 멈추고 알림
  - 시간에 맞추기: 정한 시간 25분, 남은 분량으로 계산한 속도가 식과 맞는지, 시간 넘김 알림
  - 준비 화면으로 바꾸거나 서재로 가면 꺼짐
  - 손바닥 터치(radius 70)로는 멈추지 않음
  - 흐르는 동안 16분 무입력 + 멈춘 타이머여도 꺼짐 방지 유지
  - 1초당 깨움 수: 속도 9에서 약 9~10번, 멈춤에서 0번
  - 조절판 5초 뒤 접힘, 조절판 탭은 원고 탭으로 안 셈
- **기존 시험 14벌 통과.**
- **강단 막대·조절판 배치:** 폭 744 / 820 / 1032 / 1180에서 겹침 없음.
