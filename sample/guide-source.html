강단노트 사용 설명서

설교 원고를 읽고, 표시하고, 강단으로.

강단노트는 설교를 준비하는 책상에서, 그리고 말씀을 전하는 강단에서 함께하는 아이패드 원고 리더예요. 이 설명서도 원고처럼 열려 있으니, 읽으면서 애플펜슬로 마음껏 써 보세요. 틀려도 괜찮아요 — 지우개와 되돌리기가 있으니까요.

처음 5분, 이렇게 따라 해 보세요

  1. 서재 오른쪽 위 원고 불러오기를 누르고 설교 원고 PDF를 골라요.
  2. 원고가 열리면 애플펜슬로 밑줄 · 형광펜 · 동그라미를 그어 표시해요.
  3. 오른쪽 위 강단을 누르면 설교할 때 쓰는 화면이 돼요.
  4. 위쪽 타이머 설정 버튼(25분)에서 설교 시간을 정하고, 시간을 탭해 시작해요.
  5. 화면 오른쪽을 탭하며 한 화면씩 넘겨 설교해요. 왼쪽을 탭하면 이전 화면이에요.

원고는 이 아이패드 안에만 — 강단노트에는 회원 가입도, 로그인도 없어요. 원고와 필기는 이 기기 안에만 저장되고 어떤 서버로도 보내지 않아요. 인터넷이 없는 예배당에서도 그대로 동작해요.

1원고 불러오기

강단노트는 PDF 원고를 열어요. PDF에는 원고를 쓸 때 고른 글꼴이 그대로 담겨서, 어느 기기에서 열어도 쓰신 모양 그대로 보여요.

  1. 1정렬 — 최근 연 순 · 설교 날짜 순.
  2. 2원고 선택 — 여러 원고를 골라 한 번에 지워요(9장).
  3. 3원고 불러오기 — 파일 앱에서 PDF를 골라요. 여러 개도 한 번에.
  4. 4설정 — 설명서 · 백업 · 문의.
  5. 5더 보기 — 제목 바꾸기 · 지우기.
  6. 6필기 N쪽 — 필기가 있는 쪽 수예요.

원고를 넣는 세 가지 방법

  1. 서재에서 — 원고 불러오기 → 파일 앱이 열리면 iCloud Drive · 구글 드라이브 · 나의 iPad에서 PDF를 골라요.
  2. 다른 앱에서 보내기 — 파일 앱 · 메일 · 카카오톡에서 PDF를 열고 공유 → 강단노트를 누르면 바로 들어와요.
  3. 구글 드라이브 앱에서 — 원고 옆 점 세 개(더 보기) → 다음에서 열기(또는 사본 보내기) → 강단노트.
파일 이름 붙이는 요령 — ‘260921 주일예배 설교 - 제목’처럼 지으면 날짜 · 예배 · 제목이 알아서 나뉘어 정리돼요. 날짜 순 정렬과 ‘지난 설교’ 고르기도 이 날짜를 써요.
원고를 PDF로 만드는 법 — 한글: 파일 → PDF로 저장하기 · 워드: 다른 이름으로 저장 → PDF · Pages: 내보내기 → PDF · 구글 문서: 다운로드 → PDF 문서

2원고 화면 한눈에 보기

원고를 열면 준비 화면이에요. 위쪽에는 한 줄 막대, 아래쪽에는 필기 도구 막대가 있어요.

  1. 1서재로 — 원고 목록으로 돌아가요. 필기는 쓰는 즉시 저장돼 있어요.
  2. 2쪽 미리보기 — 왼쪽에 쪽 목록을 열고 닫아요(5장에서 자세히).
  3. 3제목과 쪽 — 지금 보는 쪽이 표시돼요.
  4. 4준비 · 강단 — 두 화면을 오가요. 어느 화면에서든 늘 같은 자리에 있어요.
  5. 5메뉴 — 화면 색 · 확대 · 여백 · 내보내기(6장).

펜슬은 쓰고, 손가락은 넘겨요

준비 화면에서 애플펜슬은 글씨를 쓰고, 손가락은 원고를 위아래로 넘겨요. 그래서 쓰는 동안 손바닥이 화면에 닿아도 괜찮아요.

필기는 원고에 딱 붙어 있어요. 확대하거나 아이패드를 가로로 돌려도 제자리에 그대로 있어요.

저장은 따로 안 해도 돼요

한 획을 그을 때마다 이 아이패드에 바로 저장돼요. 앱을 닫았다 열어도 그대로예요.

3애플펜슬로 준비하기

아래쪽 도구 막대에서 도구를 고르고 펜슬로 써요.

  1. 1선택(올가미) — 필기를 골라 옮겨요(4장).
  2. 2펜 — 누르는 힘에 따라 굵기가 살짝 달라져요.
  3. 3형광펜 — 아래 글씨를 가리지 않아요.
  4. 4지우개 — 부분 · 획 전체 두 가지.
  5. 5색 — 고른 도구의 색이에요.
  6. 6굵기 — 숫자는 pt(포인트).
  7. 7되돌리기 — 방금 한 일을 취소해요.
  8. 8다시하기 — 취소한 것을 되살려요.
  9. 9손가락 쓰기 — 펜슬이 없을 때.

굵기 바꾸기

굵기 버튼을 누르면 작은 창이 열려요.

  1. 1지금 화면에서의 실제 크기 미리보기
  2. 2슬라이더를 밀어 굵기를 정해요
  3. 3−/+ 로 조금씩, 숫자는 pt

지우개 두 가지

  • 부분 — 연필 지우개처럼 지나간 자리만 지워요. 밑줄의 가운데만 지울 때 좋아요.
  • 획 전체 — 닿은 획을 한 번에 통째로 지워요.
알아 두면 좋아요 — 형광펜을 대충 곧게 그어도 반듯한 줄로 정리돼요(글줄과 나란하면 수평으로). 펜슬이 없다면 손가락 쓰기를 켜세요. 이때 원고 넘기기는 두 손가락으로 해요.

4필기 옮기기 · 크기 · 회전

잘못된 자리에 쓴 필기, 너무 크거나 작게 쓴 필기도 다시 쓸 필요 없어요. 골라서 옮기고, 키우고, 돌리면 돼요.

  1. 1선택 막대 — 고른 획 수 · 지우기 · 선택 해제(X)
  2. 2크기 손잡이(오른쪽 아래) — 끌면 커지고 작아져요. 선 굵기도 함께 바뀌어요.
  3. 3회전 손잡이(왼쪽 아래 ↻) — 돌리면 가운데를 축으로 돌아가요.

따라 해 보기

  1. 도구 막대 맨 왼쪽 선택(올가미)을 눌러요.
  2. 옮기고 싶은 필기를 펜슬로 빙 둘러싸요. 한 획만 고를 때는 그 획을 톡 누르면 돼요.
  3. 옮기기 — 점선 상자 안을 펜슬이나 손가락으로 끌어요.
  4. 크기 — 오른쪽 아래 동그란 손잡이를 바깥으로 끌면 커지고, 안으로 끌면 작아져요.
  5. 회전 — 왼쪽 아래 ↻ 손잡이를 잡고 돌려요. 돌리는 동안 각도가 보이고, 0° · 90° · 180°에서 살짝 달라붙어 반듯하게 맞추기 쉬워요.
  6. 다 됐으면 빈 곳을 펜슬로 톡 누르거나 막대의 X를 눌러 선택을 풀어요.
잘못 옮겼다면 — 도구 막대의 되돌리기를 누르면 옮기기 · 크기 · 회전 전으로 한 번에 돌아가요.

5쪽 미리보기

원고가 여러 쪽일 때, 왼쪽에 쪽 목록을 펼쳐 두면 전체를 한눈에 보고 원하는 쪽으로 바로 갈 수 있어요. 필기도 작게 함께 보여서 “동그라미 친 그 대목이 몇 쪽이었더라?” 할 때 편해요.

  1. 1목록 버튼 — 누르면 열리고, 한 번 더 누르면 닫혀요. 열려 있을 때는 버튼 색이 진해져요.
  2. 2지금 보는 쪽 — 테두리로 표시돼요. 원고를 넘기면 따라 움직여요.
  3. 3다른 쪽 — 누르면 그 쪽으로 바로 가요. 아래 숫자가 쪽 번호예요.

여는 방법 세 가지

  1. 준비 화면 — 위쪽 막대 왼쪽의 목록 버튼(서재로 버튼 바로 옆)을 눌러요.
  2. 강단 화면 — 위쪽 왼쪽의 쪽 번호(예: 1 / 2)를 눌러요. 설교 중에 광고나 찬양 뒤 원하는 쪽으로 바로 돌아갈 때 좋아요.
  3. 어느 화면이든 — 메뉴(⋯) → 쪽 미리보기 스위치를 켜요.

닫는 방법

연 버튼을 한 번 더 누르면 닫혀요. 목록이 닫히면 원고가 다시 화면 가득 넓어져요.

한 번 열어 두면 기억해요 — 쪽 미리보기를 켜 두면 다음에 원고를 열 때도 열려 있어요. 글씨를 크게 보고 싶을 때는 닫아 두세요.

6읽기 편하게 — 확대 · 화면 색

  1. 1화면 색 — 밝게 · 종이 · 어둡게. 준비와 강단에 따로 기억돼요.
  2. 2확대 · 축소 — −/+ 와 ‘맞춤’(쪽 폭에 맞게 = 100%).
  3. 3여백 줄여 크게 보기 — 원고 바깥 여백을 잘라 글씨가 약 1.3배 커져요.
  4. 4쪽 미리보기 — 5장을 보세요.
  5. 5강단에서도 펜슬로 필기 — 7장을 보세요.
  6. 6필기 포함 PDF 내보내기 — 필기가 들어간 PDF를 파일 앱 · 메일 · 드라이브로 보내요.

손가락으로 확대 · 축소

  1. 두 손가락을 화면에 대고 벌리면 커지고, 오므리면 작아져요(60~250%).
  2. 100%보다 크게 보면 원고를 옆으로도 움직일 수 있어요.
  3. 원래대로 돌아오려면 메뉴 → 확대 · 축소의 맞춤을 눌러요.
더 크게 보고 싶다면 — 아이패드를 가로로 돌려 보세요. 원고가 화면 폭에 맞춰지니 글씨가 훨씬 커져요. 강단에서 거리가 멀다면 가로 화면 + 여백 줄이기를 함께 쓰면 좋아요.

7강단에서 설교하기

오른쪽 위 강단을 누르면 설교할 때 쓰는 화면이 돼요. 위쪽 막대가 강단용으로 바뀌어요.

  1. 1쪽 번호 — 누르면 쪽 미리보기
  2. 2지금 시각
  3. 3타이머 — 탭하면 시작 · 멈춤
  4. 4타이머 설정 — 시간 · 방식(8장)
  5. 5화면 색 — 밝게 · 종이 · 어둡게
  6. 6화면 꺼짐 방지 — 초록이면 켜짐
  7. 7준비 · 강단
  8. 8메뉴

넘기기

  • 화면 오른쪽을 탭하면 다음 화면, 왼쪽을 탭하면 이전 화면이에요.
  • 펜슬로 탭해도 넘어가요.
  • 블루투스 페이지 넘김 페달도 쓸 수 있어요.

이어 읽을 자리

한 화면을 통째로 넘기지 않고 앞 화면의 마지막 몇 줄을 남겨 둬요. 그리고 이어 읽을 자리에 금색 줄이 잠깐 나타나서, 눈이 어디로 가야 할지 바로 알 수 있어요.

강단에서는 필기가 꺼져 있어요

설교 중 실수로 그어지지 않도록 강단에서는 펜슬로 탭해도 넘기기만 돼요. 강단에서도 쓰고 싶다면 메뉴의 강단에서도 펜슬로 필기를 켜세요.

화면이 꺼지지 않아요

강단 화면에서는 아이패드가 저절로 잠기지 않아요. 자물쇠가 초록색이면 켜져 있다는 뜻이에요.

8설교 타이머 · 스톱워치

강단 화면 위쪽에서 설교 시간을 재요. 두 가지 방식 가운데 편한 쪽을 고르세요.

  • 타이머 — 정한 시간(예: 25분)에서 거꾸로 세요. “몇 분 남았지?”가 한눈에 보여요.
  • 스톱워치 — 00:00부터 흘러간 시간을 세요. “몇 분 했지?”가 한눈에 보여요.
  1. 1방식 — 타이머(거꾸로) · 스톱워치(흘러감)
  2. 2시간 정하기 — −5 · −1 · +1 · +5 분 (1~180분)
  3. 3자주 쓰는 시간 — 한 번에 고르기
  4. 4리셋 — 처음으로 되돌려요
  5. 5시작 · 멈춤

따라 해 보기

  1. 강단 화면 위쪽 타이머 설정 버튼(시계 모양, 25분)을 눌러요.
  2. 맨 위에서 타이머나 스톱워치를 골라요.
  3. 설교 시간을 정해요. 칩(10분 ~ 60분)을 누르거나 −/+ 로 1분씩 맞춰요.
  4. 설교를 시작할 때 시작을 누르거나, 위쪽 시간 숫자를 탭해요.

설교 중에는 이렇게

  • 멈추기 · 이어서 — 위쪽 시간 숫자를 탭할 때마다 멈추고, 다시 탭하면 이어서 세요. 광고나 특송 시간을 빼고 싶을 때 좋아요.
  • 리셋 — 타이머 설정 창의 리셋을 누르면 처음으로 돌아가요(타이머는 정한 시간, 스톱워치는 00:00).
  • 나갔다 와도 계속 — 준비 화면이나 서재로 잠깐 나가도, 앱을 닫았다 열어도 시간은 계속 흘러요.
  • 지금 시각 — 타이머 바로 왼쪽에 지금 시각(예: 오전 10:52)이 보여요.
  • 진행 줄 — 위쪽 막대 아래 가는 줄이 흐른 시간만큼 차올라요.

색으로 알려 줘요 — 타이머

대기검은색. 정한 시간(25:00)과 ‘시작’이 보여요. 아직 세지 않는 상태예요.
진행버건디색. 점이 깜빡이며 남은 시간이 줄어요.
막바지주황색. 정한 시간의 80%가 지났어요(25분이면 20분부터). 마무리할 때예요.
넘음빨간색. 정한 시간을 넘긴 만큼 +분:초로 보여 줘요.
멈춤회색. 시간을 다시 탭하면 이어서 세요.

스톱워치로 쓸 때

스톱워치에서 정한 시간은 알려 줄 시간이 돼요. 숫자는 0부터 올라가고, 색은 타이머와 똑같이 바뀌어요.

대기 — 00:00 · 시작
진행 — 흘러간 시간 · 지남
정한 시간을 넘으면 빨간색 · 넘음
설교 전에 한 번 — 예배 전에 강단 화면을 열어 타이머가 ‘대기’(검은색)인지 확인하세요. 지난주에 쓰던 시간이 남아 있다면 리셋을 눌러 두면 돼요.

9원고 정리와 백업

여러 원고 한 번에 지우기

  1. 서재에서 원고 선택을 눌러요. 카드를 길게 눌러도 돼요.
  2. 지울 원고를 탭해 골라요. 다시 탭하면 풀려요.
  3. 아래 막대에서 지우기를 누르고 한 번 더 확인해요.
  1. 1고른 원고 — 체크 표시
  2. 2지난 설교 N편 — 파일 이름 날짜가 오늘보다 앞선 원고를 한 번에 골라요
  3. 3모두 — 전부 고르기 · 풀기
  4. 4지우기
  5. 5완료 — 선택 끝내기

백업하기 · 되살리기

  1. 1사용 설명서 보기 — 이 설명서를 지웠어도 여기서 다시 열 수 있어요.
  2. 2백업 만들기 — 모든 원고와 필기를 파일 하나로 묶어요. 공유 시트에서 ‘파일에 저장’ → iCloud Drive나 구글 드라이브에 보관하세요.
  3. 3백업에서 복원 — 백업 파일을 고르면 원고와 필기가 돌아와요. 이미 있는 원고는 필기가 더 최근인 쪽을 남겨요.
  4. 4문의하기 — 불편한 점이나 바라는 기능을 메일로 보내 주세요.
꼭 백업해 두세요 — 원고와 필기는 이 아이패드 안에만 있어요. 아이패드를 바꾸거나 앱을 지우기 전, 그리고 한 달에 한 번쯤 백업 파일을 만들어 두면 안심이에요.

10자주 묻는 질문

구글 드라이브를 누르면 계속 ‘로드 중’이에요

아이패드 운영체제(iPadOS)를 업데이트한 직후, 구글 드라이브가 파일 앱과 이어지는 부분이 멈추는 일이 있어요. 파일 앱에서 구글 드라이브를 열어도 똑같이 멈춘다면 강단노트가 아니라 구글 드라이브 쪽 문제예요. 이렇게 해 보세요.

  • 구글 드라이브 앱을 열고 원고 옆 점 세 개(더 보기) → 다음에서 열기(또는 사본 보내기) → 강단노트를 고르면 바로 들어와요.
  • 구글 드라이브 앱과 iPadOS를 최신으로 업데이트하고, 아이패드를 한 번 껐다 켜 보세요. 대개 여기서 풀려요.
  • 자주 쓰는 원고는 iCloud Drive에 넣어 두면 더 안정적이에요.

펜슬로 써지지 않아요

  • 강단 화면인지 확인하세요. 강단에서는 필기가 꺼져 있어요 → 오른쪽 위 준비를 누르세요.
  • 도구가 선택(올가미)으로 되어 있으면 둘러싸기만 돼요 → 펜이나 형광펜을 고르세요.

손가락으로 쓰고 싶어요

도구 막대 맨 오른쪽 손 모양 버튼을 켜세요. 이때는 두 손가락으로 원고를 넘겨요.

강단에서 화면이 꺼져요

강단 화면 위쪽 자물쇠가 초록색인지 확인하세요. 화면 꺼짐 방지는 강단 화면에서만 켜져요. 그래도 꺼진다면 아이패드 설정 › 디스플레이 및 밝기 › 자동 잠금을 확인해 주세요.

원고를 잘못 지웠어요

백업 파일이 있다면 설정 › 백업에서 복원으로 되살릴 수 있어요. 원고 PDF는 다시 불러올 수 있지만, 필기는 백업에만 남아 있어요.

새 아이패드로 옮기고 싶어요

쓰던 아이패드에서 백업 만들기 → iCloud Drive에 저장 → 새 아이패드에 강단노트를 설치하고 백업에서 복원을 누르면 원고와 필기가 그대로 옮겨져요.

한글(hwp) · 워드 파일은 안 되나요?

지금은 PDF만 열 수 있어요. 한글이나 워드에서 PDF로 저장해 불러오세요(1장). 쓰신 글꼴과 모양이 그대로 보여서 오히려 설교 원고에는 PDF가 더 좋아요.

이 설명서를 지웠어요

서재 오른쪽 위 설정 › 사용 설명서 보기를 누르면 다시 열려요.

11연습해 보기

① 애플펜슬로 이 문장 아래에 밑줄을 그어 보세요. 펜슬로는 글씨가 써지고, 손가락으로는 화면이 넘어가요.

② 아래 문장에 형광펜을 대충 곧게 그어 보세요. 반듯한 줄로 정리돼요.

주님은 나의 목자이시기에, 오늘 우리가 걷는 길도 이미 알고 계십니다.

③ 위에 그은 밑줄의 가운데만 부분 지우개로 지워 보세요.

④ 선택 도구로 형광펜을 둘러싸 고른 뒤, 끌어서 옮기고, 오른쪽 아래 손잡이로 키우고, ↻ 손잡이로 돌려 보세요.

⑤ 위쪽 목록 버튼으로 쪽 미리보기를 열고, 1쪽을 눌러 처음으로 돌아가 보세요.

⑥ 두 손가락으로 벌려 크게 보고, 메뉴의 ‘맞춤’으로 돌아와 보세요.

⑦ 오른쪽 위 ‘강단’을 누르고 화면 오른쪽을 탭해 넘겨 보세요. 타이머 설정에서 5분을 고르고 시간을 탭하면 버건디색으로 돌아가요. 스톱워치로도 바꿔 보세요.

좋은 설교는 책상에서 한 번, 강단에서 또 한 번 완성돼요. 책상에서는 원고를 고치고 표시하며 준비하고, 강단에서는 그 표시를 따라 말씀을 전해요.
