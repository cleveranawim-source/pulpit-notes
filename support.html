강단노트 도움말

설교 원고 PDF를 아이패드에서 읽고, 애플펜슬로 표시하고, 강단에서 넘겨 보는 앱입니다.

원고를 PDF로 만드는 법

  • 한글: 파일 메뉴 → ‘PDF로 저장하기’
  • 워드: 파일 → 다른 이름으로 저장 → 파일 형식 ‘PDF’
  • Pages: 파일 → 내보내기 → PDF
  • 구글 문서: 파일 → 다운로드 → PDF 문서

만든 PDF를 iCloud Drive나 구글 드라이브에 저장한 뒤, 서재에서 ‘원고 불러오기’를 누르고 고르면 됩니다.

자주 묻는 질문

손가락으로 화면을 만지면 글씨가 써져요.
펜 도구 줄 오른쪽의 손 모양 버튼이 켜져 있으면 손가락으로 씁니다. 끄면 손가락은 스크롤, 필기는 애플펜슬로 합니다.
강단 화면에서 어떻게 넘기나요?
화면 오른쪽을 탭하면 다음 화면, 왼쪽을 탭하면 이전 화면으로 넘어갑니다. 블루투스 페이지 넘김 페달도 쓸 수 있습니다.
강단 화면에서 화면이 꺼져요.
강단 화면은 화면 꺼짐을 막습니다. 그래도 꺼진다면 아이패드 설정 → 디스플레이 및 밝기 → 자동 잠금을 확인해 주세요.
새 아이패드로 원고를 옮기고 싶어요.
서재의 설정 → ‘백업 만들기’로 백업 파일을 저장한 뒤, 새 기기에서 설정 → ‘백업에서 복원’을 누르세요. 원고와 필기가 함께 옮겨집니다.
한글(hwp · hwpx)이나 워드(docx) 파일을 바로 열 수 있나요?
지금은 PDF만 엽니다. PDF에는 원고를 쓸 때 고른 글꼴이 그대로 담겨서, 쓰신 모양 그대로 볼 수 있습니다.
